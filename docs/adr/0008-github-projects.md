# ADR 0008: GitHub Projects para la organización del desarrollo

## Estado

Accepted.

## Contexto

El equipo necesita organizar el trabajo de UrbanPulse, consultar su estado y coordinar las tareas durante el desarrollo.

## Opciones consideradas

1. Utilizar GitHub Projects.
2. Gestionar las tareas únicamente con incidencias y listas del repositorio.
3. Utilizar una herramienta externa de gestión de proyectos.

## Decisión

Utilizar GitHub Projects para organizar y seguir el desarrollo de UrbanPulse. Esta decisión documenta la forma de trabajo del equipo.

## Consecuencias

- El equipo puede consultar y organizar el trabajo desde el entorno de GitHub.
- La utilidad del tablero depende de mantener actualizadas las tareas y sus estados.
- El proceso de seguimiento queda vinculado a GitHub y a la configuración que acuerde el equipo.
- Las columnas, los responsables y las reglas de uso deben concretarse según la organización real del proyecto.
